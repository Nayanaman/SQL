# Language School Database

## 📖 Описание
Реляционная база данных для управления учебным процессом в языковой школе.

### Сущности:
- **People/Student/Teacher** — наследование ролей
- **Course/Level/Language** — учебные программы
- **Group/Lesson/Schedule** — планирование занятий
- **Attendance/Test/Payment** — учет успеваемости и финансов

## 🗄️ Структура БД
- 15+ таблиц
- Внешние ключи с ON DELETE CASCADE
- Ограничения CHECK, UNIQUE, NOT NULL
- Представления (Views)

## 📝 Примеры запросов
В репозитории представлены запросы на:
- Многотабличные соединения (JOIN)
- Агрегацию данных (GROUP BY, HAVING)
- Подзапросы и представления
- Работу с датами (EXTRACT)
- UNION и другие операции множеств
